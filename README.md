### 💼 HireHub: Simple Job Portal
`Java` `Spring Boot` `MySQL` `HTML` `CSS` `JavaScript`

A simple job portal where recruiters post openings and candidates browse, search and apply, built with a Spring Boot REST backend and a plain HTML, CSS and JavaScript frontend.

- ➕ Post, edit and delete job openings
- 🔍 Browse and search jobs by title and location
- 📝 Apply to a job with a simple application form
- 🗄️ Data stored in **MySQL** through Spring Boot
- 🌐 Clean frontend built with **HTML, CSS and JavaScript** that talks to the REST API

[🔗 View the repository](https://github.com/UdayandSawant/hirehub-job-portal)

### 📦 E-Commerce Data Pipeline
`Python` `SQL Server` `SQLAlchemy`

- 🗄️ Designed a **relational database schema** covering customers, orders, products, order items and payments
- 🔄 Built a pipeline that cleans, merges and loads **5 linked datasets** into the database programmatically
- 🧠 Wrote advanced SQL with **window functions** (`NTILE`, `LAG`, `ROW_NUMBER`) for segmentation and month-over-month growth
- 📊 Delivered a dashboard that surfaced a **56.6% late-delivery rate**
